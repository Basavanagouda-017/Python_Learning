# 🏧 ATM Management System

## About the Project

This is a simple ATM Management System that I built using Python while learning Python fundamentals.

The main purpose of this project was to practice concepts like functions, loops, conditional statements, user input, and program flow by building a real project instead of only solving small programs.

---

## Features

- Check Balance
- Deposit Money
- Withdraw Money
- Exit the Program
- Handles Invalid Menu Choices
- Checks for Insufficient Balance

---

## Concepts Used

- Functions
- Variables
- User Input
- if-elif-else
- while Loop
- Global Variables
- Basic Python Syntax

---

## What I Learned

While building this project, I learned:

- How to divide a project into multiple functions
- How to use loops to keep a program running
- How to update and use variables across functions
- How to take input from the user
- How to build a simple menu-driven application
